## 🔍 프로젝트 구조 개요

### 1. 메인 애플리케이션 (`app/` 디렉토리)
- `Home.py`: 애플리케이션 진입점
- `pages/`: 멀티페이지 Streamlit 앱 구성
  - `01_💬_Chat.py`: 문서 기반 채팅 인터페이스
  - `02_🔍_Document_Search.py`: 문서 검색 인터페이스
  - `03_⚙️_Settings.py`: 앱 설정 관리
- `utils/`: 유틸리티 함수들
  - `display.py`: UI 관련 표시 함수
  - `session.py`: 세션 상태 관리
- `config.py`: 애플리케이션 설정 관리

### 2. LangChain 모듈 (`langchain_modules/` 디렉토리)
- `chains.py`: 질의응답 체인 구현
- `prompts.py`: 프롬프트 템플릿 정의
- `agents.py`: 문서 검색 에이전트 구현

### 3. RAG 구현 (`rag/` 디렉토리)
- `embeddings.py`: 임베딩 모델 설정
- `vectorstore.py`: 벡터 데이터베이스 관리 (FAISS, Chroma, Pinecone 지원)
- `retriever.py`: 문서 검색기 구현
- `document_loader.py`: 다양한 형식의 문서 로드 (PDF, TXT, DOCX, CSV, MD)

### 4. 데이터 처리 (`scripts/` 디렉토리)
- `ingest.py`: 문서 처리 및 벡터 스토어에 저장하는 스크립트

## 🚀 주요 기능

1. **문서 업로드 및 처리**
   - 다양한 형식의 문서 지원 (PDF, TXT, DOCX, CSV, MD)
   - 문서 청킹 및 벡터 데이터베이스 저장

2. **대화형 문서 질의응답**
   - RAG 기반 질의응답 시스템
   - 사용자 질문에 대한 문서 기반 답변
   - 답변 소스 표시 기능

3. **문서 검색**
   - 키워드 기반 문서 검색
   - 검색 결과 시각화 (관련성 차트)
   - 메타데이터 필터링

4. **설정 관리**
   - 모델 설정 (LLM, 임베딩 모델)
   - RAG 매개변수 조정 (청크 크기, 겹침)
   - 벡터 데이터베이스 선택 (FAISS, Chroma, Pinecone)

## 💡 모듈식 개발 이점

이 프로젝트는 모듈식으로 설계되어 다음과 같은 이점이 있습니다:

1. **팀 협업**: 각 팀원이 특정 모듈에 집중하여 개발 가능
   - 프론트엔드 개발자: `app/` 디렉토리
   - 백엔드/인프라 개발자: LangChain 통합 및 서버 설정
   - 데이터/AI 엔지니어: `rag/` 디렉토리 및 데이터 파이프라인

2. **유연한 확장성**:
   - 새로운 문서 형식 지원 추가 용이
   - 다양한 벡터 데이터베이스 지원
   - 새로운 LLM 모델 통합 간소화

3. **개발 효율성**:
   - 명확한 인터페이스로 독립적인 개발 가능
   - 코드 재사용 및 모듈화
   - 빠른 프로토타이핑과 반복 개발

이 코드 베이스를 활용하면 해커톤 기간 동안 효율적으로 협업하면서 기능적인 RAG 시스템을 빠르게 구축할 수 있습니다. 각 팀원은 자신의 전문 영역에 집중하면서도 통합된 시스템을 개발할 수 있습니다.
