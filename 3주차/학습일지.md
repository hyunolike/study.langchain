### 1. 출력파서
- LangChain의 출력파서는 언어 모델(LLM)의 출력을 더 유용하고 구조화된 형태로 변환하는 중요한 컴포넌트
- 응답값을 바꿔준다!👀 (구조화된 데이터 쉽게 변환 가능)

#### 1.1 Pydantic 출력 파서(PydanticOutputParser)
- 사용자가 필요로 하는 정보를 명확하고 체계적인 형태로 제공

#### 1.2 CommaSeparatedListOutputParser
- 쉼표로 구분된 항목 목록을 반환할 필요가 있을 때 유용

### 2. 텍스트 분할(Text Splitter)
- 효율적인 작은 규모의 조각으로 나누는 작업
    - 사용자가 입력한 질문에 대하여 보다 효율적인 정보만 압축/선별하여 가져오기 위함

#### 2.1 MarkdownHeaderTextSplitter
- 마크다운 파일의 특정 부분, 즉 헤더별로 내용을 나누고 싶을 때

### 3. 메모리
#### 3.1 InMemoryChatMessageHistory
> [공식문서](https://python.langchain.com/api_reference/core/chat_history/langchain_core.chat_history.InMemoryChatMessageHistory.html)


- langchain_core.chat_history.InMemoryChatMessageHistory
- 채팅 메시지 > 메모리 구현
- 키워드 인수에서 입력 데이터를 구문 분석하고 검증하여 새 모델 생성

### 4. Retrieval Augmented Generation(RAG)✌️
- 정보 검색과 생성을 통합하는 방법론
#### 4.1 RAG의 8단계 프로세스
1. 사전 준비단계
    1. 도큐먼트 로드 (Document Loader)
    2. 텍스트 분할 (Text Splitter)
    3. 임베딩 (Embedding)
    4. 벡터스토어(Vector Store) 저장
2. 런타임(RunTime 단계)
    1. 검색기 (Retriever)
    2. 프롬프트 (Prompt)
    3. LLM (Large Language Model)
    4. 체인(Chain) 생성
#### 4.1 이전 대화를 기억하는 Chain 생성방법
- 대화를 기록하는 체인 생성(chain_with_history)
