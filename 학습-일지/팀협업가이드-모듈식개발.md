## 🧩 모듈식 개발을 위한 프로젝트 구조
### 1. 폴더 구조 설계
```
project-root/
│
├── app/                      # Streamlit 앱 관련 코드
│   ├── pages/                # 멀티페이지 컴포넌트
│   │   ├── chat_page.py      # 채팅 인터페이스
│   │   └── search_page.py    # 검색 인터페이스
│   ├── Home.py               # 메인 페이지
│   └── utils/                # UI 유틸리티
│       ├── display.py        # 디스플레이 함수
│       └── session.py        # 세션 관리
│
├── langchain_modules/        # LangChain 관련 모듈
│   ├── chains.py             # 체인 정의
│   ├── agents.py             # 에이전트 정의
│   └── prompts.py            # 프롬프트 템플릿
│
├── rag/                      # RAG 관련 모듈
│   ├── document_loader.py    # 문서 로딩
│   ├── embeddings.py         # 임베딩 생성
│   ├── vectorstore.py        # 벡터 저장소 관리
│   └── retriever.py          # 검색기 구현
│
├── data/                     # 데이터 관련
│   ├── processed/            # 처리된 데이터
│   └── raw/                  # 원본 데이터
│
└── config.py                 # 전역 설정
```

### 3. 모듈 담당자 배정
#### 프론트엔드 개발자
```
app/ 디렉토리 담당
Streamlit UI 구현
사용자 경험 최적화
```

#### 백엔드/인프라 개발자
```
langchain_modules/ 담당
클라우드 인프라 설정
API 통합
```

#### 데이터/AI 엔지니어
```
rag/ 디렉토리 담당
문서 처리 파이프라인
임베딩 및 검색 로직
```

### 4. 통합 접점
```
config.py: 모든 모듈이 공유하는 전역 설정
app/Home.py: 메인 애플리케이션 진입점
langchain_modules/chains.py: RAG와 LLM을 연결하는 체인
```
