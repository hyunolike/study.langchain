## 머신러닝 학습방법
> [참고자료](https://ebbnflow.tistory.com/165)

### 1. 지도 학습(Supervised Learning)
```
레이블이 있는 데이터를 사용하여 모델을 훈련
입력과 정답을 함께 제공하여 패턴을 학습
예: 분류(Classification), 회귀(Regression)
대표적 알고리즘: 선형 회귀, 로지스틱 회귀, 결정 트리, 랜덤 포레스트, SVM, 신경망
```

### 2. 비지도 학습(Unsupervised Learning)
```
레이블이 없는 데이터에서 패턴을 발견
데이터의 구조나 관계를 스스로 학습
예: 군집화(Clustering), 차원 축소(Dimensionality Reduction)
대표적 알고리즘: K-means, DBSCAN, PCA, 오토인코더
```

### 3. 강화 학습(Reinforcement Learning)
```
환경과 상호작용하며 보상을 최대화하는 행동 정책 학습
에이전트가 취한 행동에 따라 보상이나 페널티 부여
예: 게임 AI, 로봇 제어
대표적 알고리즘: Q-learning, DQN, SARSA, PPO
```

---
### 🎯 지도 학습 (Supervised Learning)
- 📊 **선형 회귀 (Linear Regression)**
  - 연속적인 값 예측
  - 주택 가격, 판매량 예측 등에 활용
  
- 🔄 **로지스틱 회귀 (Logistic Regression)**
  - 이진 분류 문제 해결
  - 스팸 이메일 분류, 질병 진단 등에 활용
  
- 🌳 **결정 트리 (Decision Tree)**
  - 트리 형태로 데이터 분할
  - 이해하기 쉬운 규칙 기반 모델
  - 신용 평가, 의사 결정 지원에 활용
  
- 🌲 **랜덤 포레스트 (Random Forest)**
  - 여러 결정 트리의 앙상블
  - 과적합 감소, 정확도 향상
  - 이미지 분류, 금융 분석에 활용
  
- 🔍 **서포트 벡터 머신 (SVM)**
  - 최적의 결정 경계 탐색
  - 고차원 데이터에 효과적
  - 얼굴 인식, 텍스트 분류에 활용
  
- 🧠 **신경망 (Neural Networks)**
  - 인간 뇌의 구조 모방
  - 복잡한 패턴 학습 가능
  - 이미지 인식, 자연어 처리 등 다양한 분야에 활용

### 🧩 비지도 학습 (Unsupervised Learning)
- 📍 **K-means**
  - 데이터를 K개 클러스터로 그룹화
  - 고객 세분화, 이미지 압축에 활용
  
- 🔢 **DBSCAN**
  - 밀도 기반 클러스터링
  - 불규칙한 형태의 클러스터 식별
  - 이상 탐지, 공간 데이터 분석에 활용
  
- 📉 **주성분 분석 (PCA)**
  - 데이터 차원 축소
  - 중요 특성 보존
  - 데이터 시각화, 노이즈 제거에 활용
  
- 🏗️ **오토인코더 (Autoencoder)**
  - 데이터 압축 및 재구성
  - 특성 추출, 이상 탐지에 활용

### 🎮 강화 학습 (Reinforcement Learning)
- 📝 **Q-learning**
  - 보상 기반 값 함수 학습
  - 테이블 형태의 정책 학습
  - 간단한 게임, 로봇 제어에 활용
  
- 🎯 **DQN (Deep Q-Network)**
  - 신경망 기반 Q-learning
  - 복잡한 환경에서 효과적
  - 아타리 게임, 자율 주행에 활용
  
- 🔄 **SARSA**
  - 현재 정책 기반 학습
  - 안전한 정책 학습
  - 실시간 의사 결정 시스템에 활용
  
- 🚀 **PPO (Proximal Policy Optimization)**
  - 안정적인 정책 업데이트
  - 연속적 행동 공간에 효과적
  - 로봇 제어, 복잡한 시뮬레이션에 활용

|  | 결정 트리 | 분류/회귀 | 트리 구조의 규칙 기반 결정 | 해석 용이, 비선형 관계 학습 | 과적합 위험 | 신용 평가, 의사 결정 시스템 |

|  | SVM | 분류/회귀 | 최적의 결정 경계(초평면) 탐색 | 고차원 데이터에 효과적 | 대규모 데이터셋에 비효율적 | 얼굴 인식, 텍스트 분류 |

|  | KNN | 분류/회귀 | 가장 가까운 K개 이웃 기반 | 단순하고 구현 쉬움 | 고차원에서 성능 저하, 계산 비용 | 추천 시스템, 패턴 인식 |

|  | DBSCAN | 클러스터링 | 밀도 기반 데이터 그룹화 | 불규칙한 형태 클러스터 탐지 | 밀도 파라미터 설정 어려움 | 이상 탐지, 공간 데이터 분석 |

|  | DQN | 값 기반 | 신경망 기반 Q-learning | 복잡한 상태 공간 처리 | 학습 안정성 이슈 | 아타리 게임, 자율 주행 |
|  | SARSA | 값 기반 | 현재 정책 기반 학습 | 안전한 학습 | 탐험-활용 균형 어려움 | 실시간 의사 결정 시스템 |
|  | PPO | 정책 기반 | 신뢰 지역 기반 정책 최적화 | 안정적인 학습, 효율적 | 구현 복잡성 | 복잡한 로봇 제어, 시뮬레이션 |

### KNN과 K-means 비교

| 특성 | K-최근접 이웃 (KNN) | K-평균 (K-means) |
|------|---------------------|-----------------|
| **학습 유형** | 지도 학습 | 비지도 학습 |
| **목적** | 분류 또는 회귀 | 데이터 클러스터링 |
| **K의 의미** | 고려할 이웃의 수 | 생성할 클러스터의 수 |
| **작동 방식** | 새 데이터와 가장 가까운 K개의 이웃을 찾고 다수결/평균으로 예측 | 데이터를 K개의 클러스터로 할당하고 중심점 계산을 반복 |
| **학습 특성** | 게으른 학습(Lazy learning) - 예측 시점에 계산 | 적극적 학습(Eager learning) - 모델 생성 후 중심점만 저장 |
| **메모리 요구** | 모든 훈련 데이터 저장 필요 | 클러스터 중심점만 저장 |
| **계산 비용** | 예측 시 비용 높음 | 학습 시 비용 높음, 예측 시 낮음 |
| **사용 사례** | 추천 시스템, 패턴 인식, 이미지 분류 | 고객 세분화, 이미지 압축, 문서 군집화 |


### 클러스터링(Clustering)

1. **학습 유형**: 비지도 학습 - 레이블이 없는 데이터를 사용합니다.
2. **출력 유형**: 데이터 포인트들의 그룹(클러스터) 할당
3. **목적**: 유사한 특성을 가진 데이터 포인트들을 자동으로 그룹화합니다.
4. **예시**: 고객 세분화, 문서 군집화, 이미지 압축, 이상 탐지 등
5. **평가 지표**: 실루엣 점수, 데이터 내 분산, 데이터 간 분산, DB 인덱스 등
6. **알고리즘 예시**: K-means, DBSCAN, 계층적 클러스터링, Gaussian Mixture Models 등

### 회귀, 분류, 클러스터링의 비교

| 특성 | 회귀(Regression) | 분류(Classification) | 클러스터링(Clustering) |
|------|-----------------|---------------------|----------------------|
| **학습 유형** | 지도 학습 | 지도 학습 | 비지도 학습 |
| **학습 데이터** | 레이블이 있는 데이터 | 레이블이 있는 데이터 | 레이블이 없는 데이터 |
| **출력 유형** | 연속적인 값 | 이산적인 범주(클래스) | 데이터 그룹(클러스터) |
| **목적** | 연속적인 값 예측 | 범주 예측 | 유사한 데이터 그룹화 |
| **예측 질문** | "얼마나?" | "어떤 종류인가?" | "어떤 그룹에 속하는가?" |
| **사용 사례** | 주택 가격, 매출 예측 | 스팸 분류, 질병 진단 | 고객 세분화, 이상 탐지 |

### 클러스터링의 주요 특징
1. **사전 레이블 없음**: 분류나 회귀와 달리 학습 과정에서 정답(레이블)이 주어지지 않습니다.
2. **자연적 구조 발견**: 데이터의 내재된 패턴과 구조를 발견하는 데 중점을 둡니다.
3. **주관적 평가**: 클러스터링 결과의 좋고 나쁨은 종종 응용 분야와 목적에 따라 주관적으로 평가됩니다.
4. **클러스터 수 결정**: 많은 클러스터링 알고리즘(예: K-means)에서는 클러스터 수를 사전에 결정해야 합니다. 최적의 클러스터 수를 찾는 것이 중요한 과제입니다.
5. **다양한 거리 측정**: 클러스터링은 데이터 포인트 간의 유사성/거리 측정에 크게 의존합니다(유클리드 거리, 맨해튼 거리, 코사인 유사도 등).
