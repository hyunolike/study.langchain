## 프로젝트 개발 순서 (LangChain) feat. 팀 협업 가이드
1. 환경 준비
2. 데이터 확보
3. 모델 개발
    - 추천 LLM
    - 추천 API
4. 프론트 개발 (Gradio, Streamlit)

### 팀 역할 분담
#### 1. 백엔드/인프라 개발자
```
랭체인 파이프라인 구축
벡터 데이터베이스 설정 및 관리
API 개발 및 서버 인프라 구축
```

#### 2. 프론트엔드/UX 개발자
```
사용자 인터페이스 설계 및 구현
백엔드 API와의 연동
사용자 경험 최적화
```

#### 3. 데이터/AI 엔지니어
```
RAG 시스템 구현
데이터 수집 및 전처리
프롬프트 엔지니어링 및 모델 튜닝
```

### 개발 타임라인
#### 1단계. 계획 및 설정
```
모든 팀원: 프로젝트 아이디어 구체화, 기술 스택 결정
백엔드: 개발 환경 설정, 랭체인 초기 설정
데이터/AI: 필요한 데이터 소스 식별, 데이터 수집 시작
프론트엔드: 와이어프레임 설계
```

#### 2단계. 핵심 기능 개발
```
백엔드: 랭체인 체인/에이전트 구축, API 엔드포인트 개발
데이터/AI: 벡터 데이터베이스 구축, RAG 모델 구현
프론트엔드: 기본 UI 구현, API 연동 시작
```

#### 3단계. 통합 및 마무리
```
모든 팀원: 시스템 통합 및 버그 수정
백엔드/데이터: 성능 최적화
프론트엔드: UI 개선 및 사용자 경험 향상
모든 팀원: 발표 준비 및 데모 연습
```

#### 📚 구조 설명
##### 🔹 Backend
```
app/: 주 애플리케이션 코드

api/: API 라우트 및 엔드포인트
core/: 설정 및 보안 관련 코드
langchain_modules/: LangChain 컴포넌트 (체인, 에이전트, 프롬프트)
rag/: RAG 관련 컴포넌트 (임베딩, 리트리버, 벡터스토어)
utils/: 유틸리티 함수
```

#### 🔹 Frontend
```
public/: 정적 파일
src/: 소스 코드

components/: React 컴포넌트
pages/: 페이지 컴포넌트
services/: API 통신 서비스
```

#### 🔹 Data
```
raw/: 원본 문서 및 데이터
processed/: 처리된 데이터 및 임베딩
scripts/: 데이터 처리 스크립트
```

### 🤝 해커톤 팀 협업 가이드
#### 📋 협업 도구 설정
1. **코드 버전 관리**
   - **GitHub/GitLab**: 공통 레포지토리 생성
   - 브랜치 전략: `main`, `dev`, 기능별 브랜치 (`feature/chat-ui`, `feature/rag-implementation` 등)
   - PR/MR 템플릿 간단히 설정
2. **커뮤니케이션**
   - **Discord/Slack**: 실시간 소통 채널 (일반, 백엔드, 프론트엔드, 기술 공유)
   - **Zoom/Google Meet**: 필요시 빠른 화상 회의
3. **프로젝트 관리**
   - **Trello/Notion**: 간단한 칸반 보드로 작업 현황 관리
   - **단계**: Backlog → To Do → In Progress → Review → Done

#### 🔄 작업 흐름

##### 📌 초기 설정 (1-2시간)
1. **킥오프 미팅**
   - 프로젝트 비전 및 핵심 기능 정의
   - 역할 공식 배분 및 책임 영역 설정
   - 기술 스택 최종 확정

2. **개발 환경 통일**
   - 레포지토리 클론 및 초기 설정
   - 필수 패키지/라이브러리 설치
   - 각 팀원 로컬 환경 테스트

#### 🔄 일일 협업 루틴

1. **🌞 스탠드업 미팅 (15분)**
   - 전날 완료한 작업
   - 오늘 진행할 작업
   - 차단 요소/도움 필요 사항

2. **👨‍💻 페어 프로그래밍 세션 (필요시)**
   - 복잡한 기능은 2명이 함께 작업
   - 예: AI 엔지니어 + 백엔드 개발자가 RAG 파이프라인 구현

3. **🔚 마무리 체크인 (15분)**
   - 진행 상황 공유
   - 다음 스텝 계획
   - 병목 현상 해결

#### 🔀 인터페이스 정의

##### API 계약
백엔드와 프론트엔드 사이에 명확한 API 계약을 초기에 정의:

```
GET /api/search?query={query}
POST /api/chat
{
  "message": "사용자 메시지",
  "context": {optional context}
}
```

##### 데이터 포맷 표준화
```json
{
  "response": "AI 응답 텍스트",
  "sources": [
    {
      "title": "문서 제목",
      "snippet": "관련 내용",
      "relevance": 0.95
    }
  ]
}
```
