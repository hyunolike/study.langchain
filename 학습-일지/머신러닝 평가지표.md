# 머신러닝 평가 지표


---

## 1. 분류 (Classification) 평가 지표
분류 모델은 데이터를 특정 클래스(레이블)로 분류하는 문제를 다룹니다.

- **정확도(Accuracy)**  
  \[
  Accuracy = \frac{TP + TN}{TP + TN + FP + FN}
  \]  
  전체 데이터에서 맞춘 비율 (클래스 불균형에 취약)  

- **정밀도(Precision)**  
  \[
  Precision = \frac{TP}{TP + FP}
  \]  
  Positive로 예측한 것 중 실제 Positive 비율 (False Positive 줄이는 게 중요할 때)  

- **재현율(Recall, Sensitivity)**  
  \[
  Recall = \frac{TP}{TP + FN}
  \]  
  실제 Positive 중 모델이 Positive로 맞춘 비율 (False Negative 줄이는 게 중요할 때)  

- **F1 Score**  
  \[
  F1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}
  \]  
  Precision과 Recall의 조화 평균 (균형이 중요한 경우)  

- **ROC-AUC (Receiver Operating Characteristic - Area Under Curve)**  
  모델의 분류 능력을 종합적으로 평가 (1에 가까울수록 좋음)  

- **PR-AUC (Precision-Recall Curve)**  
  불균형 데이터에서 유용한 평가 지표

## 2. 회귀 (Regression) 평가 지표
회귀 모델은 연속적인 숫자 값을 예측하는 문제를 다룹니다.

- **MSE (Mean Squared Error, 평균제곱오차)**  
  \[
  MSE = \frac{1}{n} \sum (y_i - \hat{y}_i)^2
  \]  
  오차를 제곱해서 계산하므로, 큰 오차에 민감함.  

- **RMSE (Root Mean Squared Error, 평균제곱근오차)**  
  \[
  RMSE = \sqrt{MSE}
  \]  
  MSE의 단위를 원래 값과 동일하게 만들기 위해 루트를 씌운 것.  

- **MAE (Mean Absolute Error, 평균절대오차)**  
  \[
  MAE = \frac{1}{n} \sum |y_i - \hat{y}_i|
  \]  
  절대값을 사용하여 오차를 계산 (MSE보다 이상치에 덜 민감).  

- **R² Score (결정 계수, 설명력)**  
  \[
  R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}
  \]  
  1에 가까울수록 좋은 모델, 0이면 평균값 예측과 동일.

## 3. 군집 (Clustering) 평가 지표
군집 모델은 데이터의 정답(레이블)이 없는 경우가 많기 때문에 내부적으로 얼마나 잘 군집이 형성되었는지 평가합니다.

- **실루엣 계수 (Silhouette Score)**  
  -1 ~ 1 사이 값으로, 1에 가까울수록 군집이 잘 분리됨.  

- **SSE (Sum of Squared Errors, 오차 제곱합)**  
  군집 내 데이터들이 중심에서 얼마나 가까운지 측정 (작을수록 좋음).  

- **Calinski-Harabasz Index**  
  클수록 군집이 밀집되어 있고 잘 분리됨.  

---

## 4. 이상 탐지 (Anomaly Detection) 평가 지표
이상 탐지는 극단적인 값이나 패턴을 탐지하는 것이 목표이므로 일반적인 분류 평가와 다릅니다.

- **Precision-Recall Curve**  
  이상 데이터는 극히 적기 때문에, 정확도가 아닌 Precision과 Recall이 중요.  

- **AUC-ROC Score**  
  정상/이상 탐지를 얼마나 잘 구분하는지 평가.  

- **F1 Score**  
  Precision과 Recall 균형을 평가.  

---

## 5. 추천 시스템 (Recommendation) 평가 지표
추천 모델은 사용자가 선호할 아이템을 얼마나 정확하게 추천하는지 평가합니다.

- **Precision@K**  
  상위 K개의 추천 중 사용자가 실제로 좋아한 아이템 비율.  

- **Recall@K**  
  사용자가 좋아한 아이템 중 상위 K개 안에 포함된 비율.  

- **NDCG (Normalized Discounted Cumulative Gain)**  
  추천 결과의 순서까지 고려하여 평가.  

---

### 📌 정리
- **분류 모델** → Accuracy, Precision, Recall, F1 Score, AUC  
- **회귀 모델** → MSE, RMSE, MAE, R² Score  
- **군집 모델** → 실루엣 계수, SSE  
- **이상 탐지** → Precision-Recall Curve, AUC-ROC  
- **추천 시스템** → Precision@K, Recall@K, NDCG  

각 문제 유형에 따라 적절한 평가 지표를 선택하는 것이 중요합니다!
